# Model Weights Directory

This directory stores the on device TFLite model weights.

## Models
- `mobilefacenet.tflite`: MobileFaceNet 128 dimension embedding model used for face clustering and person matching across burst photos.
- `face_landmark.tflite`: Google MediaPipe Face Mesh 468 point 3D landmark model used for dense facial contours, eye openness, and mesh warping.
